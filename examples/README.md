# Examples

The matching `RS-Maker-FreeCAD-v0.3.zip` release package contains `RS-Maker-v0.3-Comida.step`, `Hamburguesita-v0.3.stl`, and `Restaurante-v0.3.stl`.
These are engineering prototypes, not validated safe toys.
